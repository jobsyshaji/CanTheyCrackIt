# 🔐 Can They Crack It?

Passwords remain one of the most common attack vectors in cybersecurity. Weak passwords are vulnerable to brute-force attacks, dictionary attacks, credential stuffing, and other password-based threats.

Can They Crack It? was developed to help users understand the strength of their passwords through an engaging cyberpunk-inspired interface.

## Built With

* HTML5
* CSS3
* JavaScript
